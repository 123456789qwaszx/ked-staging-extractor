# P5 — 엑셀 연출 열 ↔ .yarn

연출 단위(커맨드 묶음)와 모션을 엑셀 열로 고친다. **`.yarn`이 값의 주인**이고 엑셀은 무손실로 왕복하는 고치기
보기다(2026-11-08 결정 — "값의 주인은 한 곳"). 게임에 들어가는 Yarn은 여전히 컴포지터만 낸다(규칙 8). 이 보기는
추출 `.yarn` · 시험 대본 · 런타임 샘플 대본을 고치는 데 쓴다.

```powershell
py -m ked_staging sheet export extract-out\영상.yarn                 # → 영상.연출.xlsx (extract --sheet로도)
py -m ked_staging sheet apply extract-out\영상.연출.xlsx --in-place     # 고친 행만 .yarn에(.bak을 남긴다)
py -m ked_staging sheet apply 영상.연출.xlsx -o 새.yarn                  # 원래 .yarn은 그대로
py -m ked_staging sheet check a.yarn b.yarn …                          # 고치지 않은 왕복이 바이트 그대로인가
```

## 엑셀 모양

**'연출' 시트** — 줄(대사 · 선택지)마다 한 행, 노드마다 끝에 '노드 끝' 행.

| 열 | 내용 | 고치기 |
|---|---|---|
| 노드 · 행 · 종류 | `Festival_Classroom` · `1`(노드 끝은 `(노드 끝)`) · 대사 / 선택지 / 노드 끝 | 보기 |
| 화자 · 대사 | `하린` · `안녕!` — 줄 끝 태그(`#line:…`)는 칸에 없고 다시 쓸 때 그대로 붙는다 | 대사 줄만 |
| 연출 | 그 줄 앞의 표현 커맨드, 한 줄에 하나. `<< >>`는 써도 되고 안 써도 된다. 이어진 커맨드는 단위로 접는다(`@등장 s1 center bust mid 18fr`) | 예 |
| 모션 | 연출 끝의 `motion` · `pause`만으로 된 꼬리(motion이 하나는 있어야 한다). 들여올 때 연출 뒤에 붙는다 | 예 |
| 확인 | `// 확인:` 주석(추출기가 단 확인할 까닭). 고치면 그 주석을 바꾸고, 비우면 지운다. 확인이 있는 행은 노랗다 | 예 |
| 열쇠 | `노드#행` — 들여올 때 행을 맞추는 이름 | 아니요 |

**'단위' 시트** — 이름 · 인자 · 단계(한 줄에 하나, `$인자`) · 설명. 내보낼 때 기본 단위를 적고, 들여올 때는 이
시트의 것을 쓴다 — 새 단위를 더해 바로 써도 된다.

| 단위 | 인자 | 단계 |
|---|---|---|
| 등장 | slot place focus depth dur | `place_$place $slot $focus 0fr` · `size $slot $depth $focus 0fr` · `fade_in $slot $dur` |
| 밀며등장 | slot place focus depth dir dist dur | 등장 + `slide_in $slot $dir $dist $dur`(fade_in 앞) — 샘플 대본 관례 |
| 배경 | key out in | `bg_fade_out bg_main $out` · `bg_sprite bg_main $key` · `bg_fade_in bg_main $in` |

접기는 편 결과가 원래와 글자까지 같을 때만 한다(긴 단위 먼저). 퇴장(`fade_out` 하나)은 단위로 두지 않았다 —
커맨드 하나를 접어 봐야 읽기가 나아지지 않는다.

**'정보' 시트** — 원래 `.yarn` 경로와 내보낼 때의 sha256 지문.

## 들여오기 규칙

- **고친 행만 다시 쓴다.** 나머지 글자(빈 줄 · 주석 · 들여쓰기 · 줄바꿈 CRLF/LF · 태그)는 바이트 그대로다.
- 고쳤는지는 칸 글자가 아니라 **편 커맨드**로 견준다 — 단위 시트를 고치거나 칸에 `<< >>`를 써도 손대지 않은 행은
  그대로다.
- 고친 행은 그 블록의 표현 커맨드 줄을 지우고 첫 커맨드 자리(없으면 그 줄 바로 앞)에 새 커맨드를 그 줄의 들여쓰기로
  쓴다. 주석 · 빈 줄 · 흐름 커맨드는 제자리에 남는다.
- 하나라도 틀리면 **아무것도 들여오지 않는다**(행마다 까닭을 모아 보여 준다).

| 들여오지 않는 것 | 까닭 |
|---|---|
| 내보낸 뒤 `.yarn`이 바뀜(지문) | 두 곳에서 고친 것을 섞지 않는다 — 다시 내보낸다(`--force`로 무시) |
| 행을 넣거나 지우거나 옮김 | 줄을 더하고 빼는 것은 `.yarn`에서 한다 |
| 선택지 줄 고치기 | 선택지는 분기 구조다 |
| 흐름 커맨드(`<<if>>` 등) 사이에 끼인 연출 고치기 | 다시 쓰면 커맨드가 분기 밖으로 옮겨진다 |
| 모르는 단위 · 인자 수 틀림 | |
| 모르는 커맨드 | 오라클의 커맨드 표(컴포지터 기본 카탈로그)로 고친 행만 본다(`--no-check`로 건너뜀) |

## 한계

- 줄 추가 · 삭제와 선택지 고치기는 하지 않는다(`.yarn`에서).
- 연출 칸은 커맨드 순서를 그대로 받는다 — 표현 커맨드와 흐름 커맨드가 섞인 블록은 이 보기에서 연출을 고치지 않는다.
- 화자 이름의 판별은 Yarn 관례(`이름: 대사`, 이름 32자 이하)다. 고친 대사 줄만 다시 쓰므로 판별이 틀려도 손대지 않은
  줄은 그대로다.
