# P1 — 구조 (끝: 2026-11-08)

영상에서 **누가 · 어디에 · 어떤 표정으로 · 어떤 배경 위에** 섰는지를 줄마다 되찾아 `.yarn`으로 낸다. 시간과 이징은
P2의 몫이라 P1의 커맨드는 시간 인자를 생략값으로 둔다. 통과 기준: 시험장 상태 일치 95% 이상.

## 결정 (2026-11-08)

- **대사 글자는 게임텍스트추출기 결과를 붙인다.** 추출기는 그 도구의 결과 엑셀('텍스트' 시트)을 읽어, 읽은 순간이 든 줄에
  붙인다. 그 도구가 쓸 게임 프로필(대사창 자리)은 이 도구가 surface-layout에서 만든다(`gte-profile`).
- **표정 시험은 임의로 만든 시험용 초상으로 한다.** 견본 초상은 표정 · 변형 그림이 모두 같아서다. `testkit.py`가 견본 위에
  표정마다 다른 눈썹 · 입 · 볼을 얹고, 변형 b는 색조를 돌린다. 시험장 전용이고 저장소에는 만드는 코드만 둔다.
- **정답 시험장은 합성 녹화다** — 샘플 대본 → 오라클 → 합성 녹화. 정답 대본이 언제나 옆에 있다.
- **오라클 시간 축(`plan`)은 P2 첫 작업으로 미룬다.** P1은 정착 화면만 보므로 합성 녹화의 전이는 커맨드의 가장 긴 시간 동안의
  OutCubic 크로스페이드로 둔다. 실제 트윈 모양(이동 · 슬라이드 튐)은 P2에서 컴포지터 `StageMotionPlan`으로 그린다.

## 관측이 자리를 찾는 방법

1. 인물 · 변형마다 `slot → cast → place_<자리> <focus> → size <크기> <focus>`를 오라클로 접어 화면 사각형을 얻는다
   (36개 안팎, 같은 사각형은 정본에 가까운 이름 하나만). `move_by 1u 0u` · `0u 1u`로 한 번씩 더 접어 u → 화면 px 환산도 얻는다
   (크기 배율이 곱해진다 — mid에서 1u = 68px).
2. 분석 배율(1/4)로 그림을 그 사각형에 그려 영상과 비교한다. 순위는 가로로 ±40px 밀어 본 가장 좋은 값으로 매겨,
   move_by로 밀린 인물도 후보에서 빠지지 않게 한다.
3. 상위 6개만 가로 · 세로 평행 이동 탐색 → ECC로 다듬고, move_by를 0.25u로 반올림한다.
4. 오차가 덮은 픽셀당 6 이상 줄면 받아들인다. 한 인물은 한 슬롯(런타임 cast 규칙).

오라클 확인: `place`는 앞 `move_by`를 지운다. `place`와 `size`는 순서를 바꿔도 같다. 이동이 남은 채 `size`만 바꾸면
처음부터 세운 자리와 다르다 → 역해석은 그때 `place`부터 다시 세운다.

- 관측을 정착 화면 한 장에서 줄 안의 시간 축으로: 커맨드마다 시작 · 길이 · 이징 맞추기(ease-golden 표)
