# 실영상 관측 시험 스크립트

다른 게임 관측 재설계(P4) 전에, 각 기술이 실영상에서 되는지 확인한 스크립트다. 추출기 본체가 아니다.
영상 · 원본 그림은 기밀이므로 `private\` 아래에 두고 경로로 넘긴다(저장소에 넣지 않는다).

| 스크립트 | 재는 것 | 확인한 결과(실영상, 1080p 기준) |
| --- | --- | --- |
| `camera.py` | 배경 원본 맞대기 → 프레임마다 카메라 배율 · 이동 | 멈춘 동안 배율 흔들림 0.02%, 이동 0.2px. 1.14배 당기기와 되돌아오기를 프레임 단위로 잡음 |
| `track.py` | 인물 원본 맞대기 → 프레임마다 자리, 카메라를 뺀 배경 위 자리 | 멈춘 동안 위치 0.1px, 크기 0.03%. 화면 끝에서 들어오는 첫 프레임부터 잡힘 |
| `alpha.py` | 그 프레임 자리로 투명도 a 풀기 | 자리를 고정하면 미끄러지는 동안 틀림 → 그 프레임 변환 필수. 화면 전체 페이드와 인물 페이드를 가를 수 있음 |
| `screen.py` | 배경 원본별 짝 수 · 채널 감쇠 | 어두운 화면은 다른 배경이 아니라 같은 배경의 감쇠(0.64)와 검은 화면 전환이었음 |
| `expr.py` | 원래 해상도 쌍별 리그전 표정 | 멈춘 프레임에서 한 표정이 나머지 29종을 모두 이김(평균 오차 방식은 1·2등 차이 10%) |

공용 함수는 `common.py`(작업 배율 0.5, 무대 = 대사창 위 400행).
설계와 수치는 Claude Docs "P4 다른 게임 관측 재설계" 문서에 있다.
